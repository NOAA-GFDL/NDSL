# Community

The NDSL community is a collaborative space for scientists, developers, and users working on next-generation Earth system modeling. Whether you're getting started, contributing code, or running experiments, we’re here to support you.

## Get Involved

We welcome contributions of all kinds:

- Reporting bugs
- Suggesting features
- Improving documentation
- Contributing code

To get started, visit our GitHub repository and check out open issues or discussions.


## GitHub

Explore the code, [open issues](https://github.com/NOAA-GFDL/NDSL/issues), and contribute:

- NDSL repository: https://github.com/NOAA-GFDL/NDSL 

Please follow contribution guidelines outlined in the repository.
