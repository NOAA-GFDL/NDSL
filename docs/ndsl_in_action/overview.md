# NDSL in Action

Several validation procedures were carried out to ensure that NDSL preserves both physical correctness and performance capabilities.

### Scientific Validation
Following numerical validation, NDSL-enabled GEOS simulations were compared against the reference Fortran to test for physical consistency using:

- Single Column Model (SCM) simulations
- GEOS-FP simulations

### Performance Benchmarking
Then, NDSL was benchmarked across multiple hardware architectures and backends to evaluate:

- CPU vs GPU acceleration
- Runtime performance
- Memory utilization
